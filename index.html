02 iOS PRODUCT · CLOUD-NATIVE PWA · HEALTH

Fitness OS

记录训练和饮食后，怎样方便地回看？

带会员和自己训练时，我都要同时看训练、饮食和身体状态。我把这些记录放进同一个 App：一句话输入后先核对日期和内容，确认保存，再到历史页查找。原生版结合 Apple Health 给出当天最小行动建议。现已独立完成阿里云 Linux 生产环境部署（FastAPI + PWA 离线打卡），接入 Cloudflare 边缘加速与自动化容灾备份。

HOW I WORK

我怎么把想法做成可用的东西

01

先看现场

带会员、自己备考、做 DM 时，先记下具体在哪一步卡住，再决定要做什么功能。

02

想清楚谁会用

页面先放眼前需要的内容。也会借鉴 Don’t be silent 的方法，考虑流量从哪来、谁愿意付费、第一单能不能成立。

03

让 AI 帮忙实现

把要改的页面、需要保留的内容和验收方式写清楚，再交给 Claude Code 或 Codex 做。

04

自己动手检查

页面能打开只是开始。我会按用户实际操作的顺序点一遍，核对保存、回看和异常状态。

05

说清做到哪一步

本地能运行、公开有样板、真机用过、外部用户验证，是不同的进度。
