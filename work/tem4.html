CASE 01 · WEB PRODUCT / EDTECH

专四备考工作台

备考时资料和错题笔记分散在几处。我想做一个页面，让自己练完题就能看到反馈，接着知道该复习什么。

角色产品发起人／真实用户／AI 协作构建者
形态本地 Web 工作台
状态本地可运行，未公开发布

THE PROBLEM

做完题后，我还要自己找解析

我的备考资料在 PDF、音频和错题笔记里。普通练习页有时还会提前露出答案，做完一题之后，下一步复习什么仍得自己想。

所以我把作答和反馈连在同一个页面：提交前不显示答案，提交后再看翻译、考点和同类题入口。进度会保存，可以回看不同年份的练习。

TRY THE LOOP

这里可以自己做两道题

公开样板用两道脱敏迁移题演示作答、提交后反馈和同类题复习。不读取或保存访问者的个人记录。

打开交互样板

SYSTEM LOOP

从原始材料到个性化复盘。

OCR／结构化→模板化练习→提交后反馈→错题回采→同类题回炉

WHAT SHIPPED

本地工作台里已经有的内容

语法与词汇

整理了 9 个年份的 180 道语法题，还有 627 道扩展题；可以按薄弱点做 5 题快练。

完形与阅读

有 9 套完形，8 个年份的阅读内容已完成。2023 年阅读仍是占位页。

听写与写作

13 套听写可以整段作答，提交后按意群复盘；9 套写作支持草稿、计时和 AI 评分结果回填。

错题复习

错题自动收集，连续答对两次后标记掌握；进度通过 localStorage、OPFS 保存，也能导入导出 JSON。

AI COLLABORATION

AI 帮忙做了什么，我又检查了什么

OCR 先提取资料，Python 脚本批量生成页面，Claude Code 和 Codex 协助实现与回归。阅读简答和写作的评分在模型端运行，再把 JSON 结果填回工作台，网页不存模型密钥，也省去直接接入模型的成本。

我保留了评分输入和审计记录，检查字数计算、局部提交会不会影响总成绩。公开样板没有放真题、付费资料或个人成绩。

PERSONAL RESULT

我自己使用后的考试结果

使用工作台辅助备考期间，我两次正式专四成绩从 53 分提高到 69 分，后来通过考试。提分也受学习投入影响；目前没有其他用户的提分验证。

VERIFIED STATUS

当前真实状态

  • 本地服务与首页、语法、阅读、听写、错题本、写作页面可访问。
  • 核心模块做过浏览器烟测与评分机制审计。
  • 2023 年阅读仍是占位骨架；2025 年完形有 4 个答案键待人工核对。
  • 没有公开真题、音频、答案解析、作文或个人成绩。
